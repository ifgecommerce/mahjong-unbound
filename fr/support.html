Assistance

Mahjong Unbound est développée par Francesco Guiducci, Italie. Pour toute assistance :

info@ifgecommerce.com

Pro est un achat unique pour cette app. Il ne débloque pas les autres apps IFG.

La progression est locale et n’est pas synchronisée entre appareils. Désinstaller l’app peut la supprimer.

Le jeu fonctionne hors ligne. Acheter ou restaurer Pro peut nécessiter une connexion et un compte Apple.

Restaurer Pro

Ouvrez Pro et choisissez Restaurer les achats avec le compte Apple utilisé pour l’achat. Une connexion est nécessaire. Pro est un achat unique, sans renouvellement automatique. La restauration ne récupère pas les progrès supprimés.

Nous contacter

Indiquez le modèle de l’appareil, la version d’iOS ou d’iPadOS, la version de l’app et les étapes permettant de reproduire le problème. N’envoyez aucun mot de passe ni donnée de paiement.
